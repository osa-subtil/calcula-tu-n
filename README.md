# Calcula tu n

Calculadora de tamaño muestral y potencia estadística. Todo se calcula en el navegador. Es una página estática (`index.html`), sin servidor, bibliotecas ni solicitudes a servicios externos.

Incluye: estimación de una proporción y de una media; t de Student independientes y apareadas; ANOVA de un factor; correlación de Pearson y de Spearman; chi cuadrado; prueba z de dos proporciones; OR; RR; regresión lineal simple y múltiple; regresión logística. Cada análisis permite calcular la n necesaria o la potencia con una n dada, e indica la fórmula y la referencia utilizadas. Para chi cuadrado se puede introducir una tabla de frecuencias de referencia para obtener el tamaño del efecto.

## Publicación con GitHub Pages

En el repositorio, abre **Settings → Pages** y selecciona **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`. Guarda los cambios para publicar el sitio.
